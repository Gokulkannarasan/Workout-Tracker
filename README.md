# 🏋️ Workout Tracker 

This is a simple web-based workout tracker application built with HTML, CSS, JavaScript, and Firebase. It allows users to log their workouts, view their workout history, and track their workout statistics.

## Features

* **User Authentication:** Secure user login and logout using Firebase Authentication.
* **Workout Logging:** Users can log their workouts by entering the exercise name, duration, and date.
* **Workout History:** Displays a list of logged workouts.
* **Workout Statistics:** Provides a summary of total workouts and total duration.
* **Data Visualization:** Uses a chart to visualize workout data.
* **Dark/Light Theme:** Toggleable theme.
* **Firebase Integration:** Uses Firebase Firestore to store workout data.

## Technologies Used

* **HTML:** For structuring the web page.
* **CSS:** For styling the web page.
* **JavaScript:** For implementing application logic and interactivity.
* **Firebase:**
    * Firebase Authentication: For user authentication.
    * Firebase Firestore: For storing workout data.

## Usage

1.  **Login:**
    * Use the login form to create an account or sign in.
2.  **Log Workouts:**
    * Enter the exercise name, duration, and date in the workout form.
    * Click the "Add workout" button to save the workout.
3.  **View Workout History:**
    * The workout history will be displayed in the "Workout history" section.
4.  **View Statistics:**
    * The workout statistics and chart will be displayed in the "Statistics" section.
5.  **Change Theme:**
    * Use the theme button to switch between light and dark mode.
6.  **Logout:**
    * Use the logout button to log out of your account.
