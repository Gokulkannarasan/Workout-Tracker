# 🏋️ Workout Tracker Web App

A **modern and responsive** workout tracker web application built using **HTML, CSS, JavaScript, and Firebase**. This app allows users to **log workouts, track their progress, switch themes (dark mode), and manage their data efficiently**.

## 🚀 Features

✔ **User Authentication** (Sign Up, Login, Logout)  
✔ **Workout Logging** (Exercise Name, Duration, Date)  
✔ **Workout History** (View all logged workouts)  
✔ **Delete Workouts** (Easily remove workouts from history)  
✔ **Dark Mode Toggle** (Light & Dark Theme Support)  
✔ **Cloud Storage with Firebase Firestore**  

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Firebase Authentication & Firestore
